# Design v2 — What Launch 디자인 리뉴얼

## 디자인 방향

- **컬러풀/비비드** 톤: 음식 서비스에 어울리는 따뜻하고 에너지 있는 색상
- **뽑기 게임 컨셉 가볍게 반영**: 추천 시 살짝 재미있는 전환 효과
- **지도 중심 UI**: 지도가 화면의 핵심, 항상 노출

## 컬러 팔레트

| 토큰 | 기준색 (500) | 용도 |
|------|------------|------|
| `primary` | `#F97316` 오렌지 | 메인 액션 버튼, 선택 상태, 포커스 링 |
| `accent` | `#EF4444` 레드 | CTA 강조, 랜덤 버튼, 호버 |
| `fresh` | `#22C55E` 그린 | 거리 뱃지, 성공 상태 |
| `surface` | `#FFFBF5` 웜 크림 | 페이지/카드 배경 (차가운 블루 대체) |

기존 blue/indigo 그라데이션 배경 → 웜 크림(`surface-50`) 배경으로 전환.

## 레이아웃

### 데스크톱 (768px 이상)
```
┌─────────────┬────────────────────┐
│  사이드 패널  │                    │
│  (w-1/3)     │    지도 영역        │
│              │    (flex-1)        │
│  ┌─────────┐ │                    │
│  │ 헤더     │ │    항상 노출       │
│  │ 위치입력  │ │    전체 높이       │
│  │ 장르선택  │ │                    │
│  │ 추천버튼  │ │                    │
│  │ 식당카드  │ │                    │
│  └─────────┘ │                    │
└─────────────┴────────────────────┘
```

### 모바일 (768px 미만)
```
┌────────────────────┐
│                    │
│    지도 영역        │  (전체 화면)
│                    │
│                    │
├────────────────────┤
│  ── 드래그 핸들 ──  │  하단 시트
│  위치입력           │  (framer-motion)
│  장르선택           │  snap: 80px / 50vh / 90vh
│  추천버튼           │
│  식당카드           │
└────────────────────┘
```

- 하단 시트는 collapsed(80px), half(50vh), full(90vh) 3단계 snap
- 식당 결과 도착 시 자동으로 half로 확장
- collapsed 상태에서 지도 터치 이벤트 차단하지 않음

## 장르 선택 UI

이모지+텍스트 버튼, 3열 그리드:

```
┌──────┐ ┌──────┐ ┌──────┐
│ 🍚   │ │ 🍣   │ │ 🥟   │
│ 한식  │ │ 일식  │ │ 중식  │
└──────┘ └──────┘ └──────┘
┌──────┐ ┌──────┐ ┌──────┐
│ 🍝   │ │ 🍽️   │ │ 🎲   │
│ 양식  │ │ 기타  │ │ 랜덤  │
└──────┘ └──────┘ └──────┘
```

- 선택: `bg-primary-500 text-white shadow-md`
- 미선택: `bg-white border-surface-200`

## 식당 카드

```
┌───────────────────────────────────┐
│ [한식 > 한정식]          [500m 📍] │  카테고리 + 거리 뱃지 강조
│                                   │
│ 맛있는 한식당                      │  식당명 크게
│ ⭐ 4.2                            │
│                                   │
│ 📍 서울 강남구 역삼동 123-4         │
│ 📞 02-1234-5678                   │
│                                   │
│ [카카오맵에서 보기]  [다시 뽑기 🎲]  │
└───────────────────────────────────┘
```

- 카테고리 뱃지: `bg-primary-100 text-primary-700`
- 거리 뱃지: `bg-fresh-100 text-fresh-700`
- 카드 등장 시 slide-up 애니메이션 (framer-motion)

## 애니메이션

| 요소 | 효과 | 구현 방법 |
|------|------|----------|
| 하단 시트 (모바일) | 드래그 up/down + snap | framer-motion `drag="y"` |
| 식당 카드 | slide-in (opacity + y) | framer-motion `motion.div` |
| 지도 마커 | 바운스 | 카카오맵 네이티브 `Animation.BOUNCE` |
| 지도 이동 | 부드러운 pan | `map.panTo()` (카카오맵 API) |
| 에러 메시지 | fade-in | framer-motion `AnimatePresence` |

## 엣지 케이스

- **결과 없음**: 에러 메시지 + "검색 범위 넓히기 (2km)" 액션 버튼
- **초기 상태**: 서울 시청 중심 기본 지도 즉시 표시
- **로딩 중**: 지도 위 반투명 오버레이 + 추천 버튼 pulse
- **브라우저 리사이즈**: ResizeObserver → `map.relayout()` 호출

## 지도

- 항상 렌더링 (조건부 렌더링 금지 → 인스턴스 유지)
- 고정 `h-96` 제거 → `w-full h-full` (부모가 크기 결정)
- `map.setCenter()` → `map.panTo()`로 변경 (부드러운 전환)
- ResizeObserver로 컨테이너 크기 변경 감지 → `map.relayout()`
